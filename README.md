# Unstamp PDF

Finds watermarks in a PDF (diagonal or faded text, repeated stamp images, watermark layers), previews the removal, and saves a clean copy. Everything runs on the user's device.

Files:
- `index.html` - the app
- `manifest.webmanifest` - app name, icons, and "open PDFs with this app"
- `sw.js` - lets the app work offline. Change `VERSION` in it every time you upload new files, so installed copies update.
- `privacy.html` - privacy policy for the Store listing
- `icons/` - app icons
